1. 생성 의도

기본 예제: 중앙 남북 강, 강가 벚꽃만, 길·바위 없음, Seed 234.

미지정 Seed는 확정 시 한 번 생성합니다. “동일 JSON 재생성”은 해석이나 Seed 추첨을 다시 하지 않습니다. 자연어 비용은 API 설정에 따르며 자동 재시도하지 않습니다.

2. 확정 요청 확인

아직 확정된 요청이 없습니다.
해석 근거와 지원 범위
확정된 실행 JSON



숲·사막·설원·습지 v4를 지원합니다. 동일 입력의 재전송은 현재 서버가 실행되는 동안 같은 요청 ID를 재사용합니다. 서버 재시작 이후 재현에는 저장한 최종 JSON을 사용하세요.




3. Unity에 생성
Unity 메뉴에서 Tools → LLM2PCG → Experimental v4 → Start HTTP Preview를 먼저 실행하세요. Play Mode는 필요 없습니다.

3D 결과는 Unity 프리뷰 창에 표시됩니다. 공개 패키지는 기본 도형 프로필을 제공합니다. 별도 에셋 프로필이 설치된 개발 환경에서만 에셋 모드와 외곽 맞춤을 선택할 수 있습니다. 외곽 맞춤은 좌표·개수를 유지하면서 모델을 축소하며, 겹침 수는 실제 메시 충돌이 아닌 보수적 외곽 원 기준입니다. 교량 경사·보행 검증은 아직 지원하지 않습니다.


4. Unity 없이 Web 3D로 생성
.NET CoreHost가 실행 중이어야 합니다. 같은 확정 JSON을 CoreHost에 보내 전체 v2 데이터를 받고, 배치를 다시 추첨하지 않고 렌더합니다. 기본 도형 프로필이며 에셋 축소·플레이어 이동은 적용하지 않습니다. 생성 실패 시 마지막 화면은 남지만 아래 상태에 실패를 표시합니다.
확정 JSON을 먼저 준비하세요.
